## 🛠️ ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Архитектура системы подписок
- **SubscriptionService**: Управление подписками
- **PaymentService**: Обработка платежей
- **AdminService**: Админ-функции
- **Middleware**: Проверка лимитов

### База данных
- **users**: Пользователи и их подписки
- **subscriptions**: Активные подписки
- **payments**: История платежей
- **analytics**: Аналитические данные

### Платёжные системы
- **Robokassa**: Основная платёжная система
- **Telegram Stars**: Альтернативный способ оплаты
- **Автоматическая проверка**: Статус платежей
