## 🎯 СЛЕДУЮЩИЕ ШАГИ

### 1. Установка зависимостей

```bash
# Python зависимости
pip install -r requirements.txt

# Node.js зависимости для веб-сайта
cd web_site
npm install
cd ..
```

### 2. Настройка окружения

```bash
# Создать .env файл
cp .env.example .env

# Отредактировать настройки
nano .env
```

**Обязательные настройки:**
- `BOT_TOKEN` - токен Telegram бота
- `OPENAI_API_KEY` - ключ OpenAI API
- `DATABASE_URL` - URL базы данных PostgreSQL

### 3. Запуск платформы

```bash
# Запустить всё одной командой
python run_platform.py
```

Или по отдельности:

```bash
# Telegram бот
cd telegram_bot
python main.py

# Веб-сайт (в другом терминале)
cd web_site
npm run dev
```

### 4. Тестирование

```bash
# Запустить тесты
python test_platform.py

# Демонстрация возможностей
python demo_platform.py
```
