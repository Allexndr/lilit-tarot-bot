## 🚀 БЫСТРЫЙ ЗАПУСК

### 1. Установка зависимостей

```bash
# Python зависимости
pip install -r requirements.txt

# Node.js зависимости для веб-сайта
cd web_site
npm install
cd ..
```

### 2. Настройка окружения

```bash
# Создать .env файл
cp .env.example .env

# Отредактировать настройки
nano .env
```

**Обязательные настройки:**
- `BOT_TOKEN` - токен Telegram бота
- `OPENAI_API_KEY` - ключ OpenAI API
- `DATABASE_URL` - URL базы данных PostgreSQL
- `ROBOKASSA_LOGIN` - логин Robokassa
- `ROBOKASSA_PASSWORD1` - пароль 1 Robokassa
- `ROBOKASSA_PASSWORD2` - пароль 2 Robokassa

### 3. Запуск платформы

```bash
# Запустить всё одной командой
python run_platform.py
```

### 4. Тестирование

```bash
# Автономное тестирование (без БД)
python standalone_test.py

# Тестирование системы подписок
python test_subscriptions.py

# Демонстрация возможностей
python demo_platform.py
```
