# 🌙 АРУАХ - Эзотерическая платформа для Казахстана

## 🎯 О ПРОЕКТЕ

**АРУАХ** (каз. "Дух") - первая в Казахстане комплексная эзотерическая платформа, объединяющая Таро, нумерологию, астрологию, чакры, матрицу судьбы и Human Design с современными AI-технологиями.

## 🏗️ АРХИТЕКТУРА

```
aruah_platform/
├── telegram_bot/          # Telegram бот (основная платформа)
├── web_site/             # Веб-сайт (презентационная витрина)
├── shared/               # Общие модули и утилиты
├── database/             # Схемы БД и миграции
├── ai_services/          # AI-сервисы и промпты
├── payment_systems/      # Платёжные системы
└── admin_panel/          # Админ-панель
```

## 🚀 БЫСТРЫЙ СТАРТ

### 1. Установка зависимостей

```bash
# Установить Python зависимости
pip install -r requirements.txt

# Установить Node.js зависимости для веб-сайта
cd web_site
npm install
cd ..
```

### 2. Настройка окружения

```bash
# Скопировать файл конфигурации
cp .env.example .env

# Отредактировать .env файл
nano .env
```

### 3. Запуск платформы

```bash
# Запустить всю платформу одной командой
python run_platform.py
```

Или запустить компоненты отдельно:

```bash
# Telegram бот
cd telegram_bot
python main.py

# Веб-сайт (в другом терминале)
cd web_site
npm run dev
```

### Добавление новых функций

1. **Новый эзотерический модуль**:
   - Создать файл в `shared/`
   - Добавить калькулятор и интерпретатор
   - Интегрировать в `telegram_bot/services.py`

2. **Новая команда бота**:
   - Добавить обработчик в `telegram_bot/handlers.py`
   - Создать клавиатуру
   - Добавить в главное меню

3. **Новая страница сайта**:
   - Создать файл в `web_site/app/`
   - Добавить роутинг
   - Обновить навигацию
