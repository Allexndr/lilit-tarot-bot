# 🌙 ЛИЛИТ - Telegram-бот Таро

Интеллектуальный Telegram-бот для эзотерических практик: расклады Таро, Матрица Судьбы, астропрогнозы и уникальные интерактивные функции.

## ✨ Основные возможности

### 🔮 Расклады Таро
- **Карта дня** - ежедневная карта для получения совета
- **Да/Нет** - четкие ответы на конкретные вопросы  
- **Путь** - расклад прошлое-настоящее-будущее на 3 карты
- **Отношения** - углубленный анализ взаимоотношений (5 карт)
- **Тень и Свет** - анализ сильных и слабых сторон (4 карты)

### 🎭 Уникальные функции
- **Диалог с Арканами** - интерактивное общение с картами Таро
- **Матрица Судьбы** - расчет по дате рождения
- **Астропрогнозы** - ежедневные, еженедельные и месячные прогнозы
- **Триггерные расклады** - автоматические расклады по ключевым словам
- **Совместные расклады** - расклады для двоих с анализом связей

### 💎 Система монетизации
- **Бесплатный доступ**: 1 расклад в день, карта дня, базовые прогнозы
- **Базовая подписка** (1000₸/мес): до 3 раскладов в день + все прогнозы
- **Премиум подписка** (2500₸/мес): безлимит + эксклюзивные функции

## 🚀 Установка и запуск

### Предварительные требования
- Python 3.10+
- PostgreSQL (опционально, по умолчанию SQLite)
- Telegram Bot Token

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd taro
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка окружения
Создайте файл `.env` на основе `config.py`:

```env
BOT_TOKEN=your_bot_token_here
DATABASE_URL=sqlite+aiosqlite:///./taro_bot.db
OPENAI_API_KEY=your_openai_key_here (опционально)
ADMIN_CHAT_ID=your_telegram_id
```

### 4. Запуск бота
```bash
python main.py
```

## 🎯 Использование

### Базовые команды
- `/start` - запуск бота и главное меню
- Все остальное управление через inline-клавиатуру

### Основные функции
1. **🔮 Карта дня** - получение ежедневной карты с советом
2. **🎯 Да/Нет** - быстрые ответы на конкретные вопросы
3. **🛤 Путь** - трехкарточный расклад на прошлое-настоящее-будущее
4. **🎭 Диалог с Арканом** - интерактивное общение с картами
5. **📊 Профиль** - просмотр статистики и настроек

## 🗄️ База данных

Проект использует SQLAlchemy ORM с поддержкой:
- **SQLite** (по умолчанию) - для разработки
- **PostgreSQL** - для продакшена

### Основные таблицы:
- `users` - пользователи и их настройки
- `tarot_cards` - карты Таро и их значения
- `readings` - история раскладов
- `destiny_matrices` - матрицы судьбы
- `payments` - информация о платежах

## 🔧 Конфигурация

Основные настройки в `config.py`:
- `BOT_TOKEN` - токен Telegram бота
- `DATABASE_URL` - строка подключения к БД
- `OPENAI_API_KEY` - ключ для AI-диалогов (опционально)
- `PAYMENT_PROVIDER_TOKEN` - токен платежной системы
